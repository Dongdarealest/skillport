## Skill: Color System

> Builds a small, disciplined color palette for an interface or brand: tinted neutrals, one accent, and the rules for where each may appear. Use when the user is starting a design, rebranding, or fixing a page that uses too many colors.

# Color System

Most interfaces fail on color because they have too much of it, spread everywhere.

## Method

1. Start with neutrals tinted toward one hue, warm or cool. Pure gray looks dead next to real content.
2. Pick one accent. It appears on the primary action, the active state, and almost nothing else.
3. Richness goes into content: photography, charts, the product itself. Chrome stays quiet.
4. Define text colors by role, not by taste: primary, secondary, faint. Three is enough.
5. Check every pairing for contrast before shipping. Beauty that cannot be read is decoration.

## Output

The palette as named tokens with hex values, plus one line per token stating where it is allowed to appear.

## Skill: Hero Section

> Designs the first screen of a landing page so a stranger understands the product in five seconds. Use when the user is building or fixing a landing page, a portfolio or a product site hero.

# Hero Section

The hero has one job: a stranger gets what this is, who it is for, and what to do next, in five seconds.

## Rules

1. One headline, one idea. If the headline needs the subtext to make sense, rewrite the headline.
2. The headline names the outcome for the visitor, not the features of the product.
3. One primary action, one secondary at most. Two equal buttons means no decision was made.
4. Show the product, not a metaphor. A real screenshot or a rendered object beats abstract shapes.
5. Leave calm space around the headline. Crowding the first screen reads as desperation.
6. Cut every word that could appear on a competitor's page unchanged.

## Output

Headline, subtext of one line, the primary action label, and a note on what visual carries the section and why.

## Skill: Interface Craft

> Reviews a screen and fixes the craft details that make software feel designed: spacing rhythm, type hierarchy, color discipline and icon consistency. Use when the user shares a UI screenshot or a page and asks for design feedback or polish.

# Interface Craft

Review the interface the way a designer redlines a screen: one layer at a time, whole screen, no spot fixes.

## Pass order

1. Spacing: one rhythm everywhere. If two gaps look almost equal, they are wrong; make them clearly equal or clearly different.
2. Type: at most three sizes in play. Headlines carry the hierarchy, not bold body text.
3. Color: quiet chrome, one accent. Richness belongs in the content, not in buttons and borders.
4. Icons: one family, one stroke weight, no emoji as labels.
5. Copy: short, specific, written for this product. If a sentence could sit on any product, rewrite it.

## Output

List the findings in pass order, each with the fix. Then apply the fixes when you have the code, or describe them precisely when you do not.
