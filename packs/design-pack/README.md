# Design Pack

Three skills that give your AI a designer's eye.

## Inside

- **color-system**: Builds a small, disciplined color palette for an interface or brand: tinted neutrals, one accent, and the rules for where each may appear.
- **hero-section**: Designs the first screen of a landing page so a stranger understands the product in five seconds.
- **interface-craft**: Reviews a screen and fixes the craft details that make software feel designed: spacing rhythm, type hierarchy, color discipline and icon consistency.

## Install

One line, in your terminal:

```bash
curl -fsSL https://raw.githubusercontent.com/Dongdarealest/skillport/main/install.sh | bash -s -- design-pack claude
```

Swap the last word for your AI: `claude`, `muse`, `cursor` or `codex`. On Windows, use `install.ps1` from the repo root the same way. For ChatGPT, download the ZIP above and paste the files in `for-chatgpt/` into your custom GPT or project instructions. Using Claude on the web instead? Zip any single skill folder inside `for-claude/` and upload it under Settings, Skills.

By hand instead? Open the folder for your AI (`for-claude`, `for-muse`, `for-cursor`, `for-codex`, `for-chatgpt`) and copy its contents where your AI keeps its skills or rules. The pack README in the repo explains each target in one line.
