# Anti-Slop Design

AI design has a uniform: gradient hero, three identical cards, rounded everything, one accent color used everywhere, type at framework defaults. People recognize it instantly and trust it less.

## Break the uniform

1. **Kill the gradient hero.** Use a flat tinted background, a real image, or type big enough to be the visual.
2. **Break the grid once.** One element larger, off-axis or overlapping beats twelve identical cards. Symmetry everywhere reads as generated.
3. **Choose a typeface on purpose.** A serif display face or a characterful grotesque changes everything downstream. Never ship the default stack at default sizes.
4. **Restraint with color.** Neutrals tinted toward one hue, one accent, used rarely. AI output spends color like it is free.
5. **Real content only.** No lorem ipsum, no "Feature One". Invent the actual product, names, numbers and words a real launch would have.
6. **One imperfect detail.** A hand-set caption, an off-grid footnote, a number that is oddly specific. Polish is fine; sterility is the tell.

## Output

The design, plus a one-line note naming which uniform habits you deliberately broke.
