## Skill: Anti Slop Design

> Designs interfaces and pages that do not look AI-generated: no purple gradient hero, no identical card grid, no default typeface at default sizes. Use when the user is generating a landing page, a UI or a visual and wants it to look designed by a person with taste.

# Anti-Slop Design

AI design has a uniform: gradient hero, three identical cards, rounded everything, one accent color used everywhere, type at framework defaults. People recognize it instantly and trust it less.

## Break the uniform

1. **Kill the gradient hero.** Use a flat tinted background, a real image, or type big enough to be the visual.
2. **Break the grid once.** One element larger, off-axis or overlapping beats twelve identical cards. Symmetry everywhere reads as generated.
3. **Choose a typeface on purpose.** A serif display face or a characterful grotesque changes everything downstream. Never ship the default stack at default sizes.
4. **Restraint with color.** Neutrals tinted toward one hue, one accent, used rarely. AI output spends color like it is free.
5. **Real content only.** No lorem ipsum, no "Feature One". Invent the actual product, names, numbers and words a real launch would have.
6. **One imperfect detail.** A hand-set caption, an off-grid footnote, a number that is oddly specific. Polish is fine; sterility is the tell.

## Output

The design, plus a one-line note naming which uniform habits you deliberately broke.

## Skill: Human Voice

> Rewrites AI-generated text so it reads like a specific person wrote it: no filler openings, no buzzwords, no identical sentence rhythm. Use when the user says a draft sounds like AI, sounds generic, or needs to sound human before it is published.

# Human Voice

Readers can smell AI text in one line. It is not the vocabulary. It is the absence of a person: no choices, no edges, no rhythm of thought.

## The tells, and the fixes

1. **The warm-up opening.** "In today's fast-paced world", "When it comes to", "It's important to note." Delete the first sentence. The piece almost always starts at sentence two.
2. **Buzzword stuffing.** Delve, leverage, seamless, robust, elevate, unlock, furthermore. Replace each with the plain word a person would say, or cut it.
3. **Metronome rhythm.** Ten sentences of the same length means no one was thinking. Vary it. A short sentence lands. Then a longer one can carry the explanation the short one set up.
4. **Hedged everything.** "Can potentially help improve" says nothing three times. Commit: "helps", with a number or an example.
5. **The summary that repeats the intro.** End on the strongest line instead of restating the piece.

## Method

Read the draft once for meaning, once aloud for rhythm. Fix the tells in order. Keep the writer's facts and stance exactly; only the voice changes. If a sentence could appear in any article on any topic, it goes.

## Output

The rewritten text, then at most three short notes on the biggest tells you removed.

## Skill: Make It Real

> Forces any AI output to be specific instead of generic: real numbers, named examples, concrete details and a stated point of view. Use when the user says an output is vague, generic, could be about anything, or needs to feel grounded and believable.

# Make It Real

Generic output fails one test: swap the topic for a different one and nothing needs to change. Real work fails that swap test on every line.

## Method

1. **Numbers with edges.** Not "many users" but "about 4,000 users, most of them on Tuesdays". If the true number is unknown, mark the estimate as an estimate instead of rounding it into fog.
2. **Names and places.** A named example the reader can check beats three abstract categories.
3. **One detail only an insider would know.** Every field has them: the annoying step, the unwritten rule, the thing beginners get wrong. Find one and include it.
4. **A point of view.** State what you would choose and why. "It depends" is allowed once, with the dependency named.
5. **Cut the interchangeable.** Read each sentence and ask: could a competitor publish this unchanged? If yes, rewrite it until the answer is no.

## Output

The revised output, with the generic lines replaced rather than annotated. Flag any place where a real fact is needed and you had to estimate.
