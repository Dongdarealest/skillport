# Release notes

## v0.3.7

The plaque at the top of the README is live now. It is served from the SkillDoctor registry site and regenerated by a daily re-audit of this repo, under the one scoring rule the registry now applies to everyone: the health the audit reports for the whole collection, 98 today. If the collection ever stops passing, the plaque flips to a recheck design on its own. The static plaque file stays in the repo as the announcement snapshot from the day it was earned.

## v0.1.0 · 2026-11-22

The store opens.

- Three ready-made packs, nine original skills: Design Pack, Writing Pack, Coding Pack.
- Every pack pre-converted for Claude, Muse, Cursor, Codex and ChatGPT, with per-platform install instructions.
